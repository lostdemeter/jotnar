# COLD-START generality protocol (v1)

The summit test: an unseen fact, in an unseen template, installed end
to end with predicted receipts -- no laddering, no surgery, no new
structures. Driver code wiring existing pieces is allowed; per-case
tuning is not (fixed operating points below).

## Procedure

1. Given (prompt, subject-substring, target-token-text):
   - address key: early subject state (layer 2, offset-mapped --
     no template assumptions, no frag lists).
   - value: target readout row (exact native content species).
   - nulls: sibling subjects' keys (hold by construction).
2. Fixed operating points: key-scale 8, gains {1, 2}, L27.
3. Predict BEFORE running: install (target top-1) at gain 1-2 +
   all controls hold + own-retrieval (windows doctrine: L27 wide).
4. Run once per cell. Grade. New failures become species with tests;
   passing by iteration is refused here (that would be calibration,
   not cold-start).

## Battery (v1)

- everest x2 templates ("The tallest mountain on Earth is" +
  paraphrase "Earth's tallest mountain is called").
- nile x2 templates ("The longest river in Africa is" + paraphrase
  "Africa's longest river is called").
- Controls per cell: all other battery prompts must hold base tops.
